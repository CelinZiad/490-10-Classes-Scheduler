Lab Rooms & Assignments

Import lab room information and course-to-room assignments. Updates the labrooms and courselabs tables.

Tables: labrooms, courselabs
Required CSV columns:
Course Code, Title, Room, Capacity, Cap_MAX, Responsible, Comments

Example row:
COEN 316, COMPUTER ARCHITECT., H-859, 14, 16, Ted, "notes"

Room format: H-859 or AITS for any computer lab. Each row = one course-room pair. Multiple rows for multiple rooms.
